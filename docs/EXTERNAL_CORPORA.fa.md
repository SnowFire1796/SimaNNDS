# راهنمای پیکره‌های بزرگ فارسی بیرونی

این سند منابع بزرگ‌تر را برای توسعهٔ آیندهٔ SimaNNDS ثبت می‌کند. هیچ‌یک از این منابع در نسخهٔ فعلی مخزن ادغام نشده‌اند. اندازهٔ زیاد به معنی مجوز بازتوزیع، کیفیت یکنواخت یا مناسب‌بودن برای هر مدل نیست.

## منابع قابل بررسی

### Persian Raw Text — persiannlp

- نشانی: https://github.com/persiannlp/persian-raw-text
- README این پروژه از مجموعه‌ای در مقیاس ده‌ها گیگابایت و منابعی مانند Common Crawl، MirasText، W2C، ویکی‌پدیای فارسی، Leipzig، VOA، شعر فارسی و TEP نام می‌برد.
- همان README هشدار می‌دهد که deduplication انجام نشده و ممکن است متن تکراری وجود داشته باشد.
- **وضعیت حقوقی در این مخزن: بررسی‌نشده.** README فهرست منابع را معرفی می‌کند، اما مجوز واحد و روشن برای تمام محتوای گردآوری‌شده ارائه نمی‌کند. تا بررسی حقوق هر منبع، محتوای آن نباید به SimaNNDS بازتوزیع شود.

### Naab — SLPL

- نشانی: https://huggingface.co/datasets/SLPL/naab
- کارت مجموعه حدود ۱۳۰ گیگابایت، ۲۵۰ میلیون پاراگراف و ۱۵ میلیارد واژه را گزارش می‌کند.
- **وضعیت حقوقی در این مخزن: مجوز قابل اتکای واحد احراز نشده است.** پیش از دانلود یا بازتوزیع باید شرایط رسمی و مجوز هر بخش بررسی شود.

### Targoman Large Persian Corpus (TLPC)

- نشانی: https://huggingface.co/datasets/Targoman/TLPC
- کارت داده بیش از ۷۵ میلیون سند و بیش از ۴۱ میلیارد توکن را گزارش می‌کند.
- مجوز اعلام‌شده در کارت: **CC BY-NC-SA 4.0**؛ استفادهٔ تجاری آزاد نیست و انتساب و شروط ShareAlike باید رعایت شوند.
- دسترسی به فایل‌ها ممکن است نیازمند پذیرش شرایط میزبان باشد.
- **وضعیت در SimaNNDS: فقط منبع پیشنهادی؛ هنوز وارد مخزن نشده است.**

### FarsTail

- نشانی: https://github.com/dml-qom/FarsTail
- مجموعهٔ استنتاج زبان طبیعی فارسی شامل ۱۰٬۳۶۷ نمونه است و train/validation/test جدا دارد.
- مخزن کد دارای فایل Apache-2.0 است، اما کارت برخی بازنشرهای مجموعه دربارهٔ حقوق خود داده درخواست اطلاعات بیشتر می‌کند.
- **وضعیت در SimaNNDS: تا روشن‌شدن دامنهٔ مجوز داده، وارد نشده است.**

## سیاست ادغام

1. مجوز فایل داده و منشأ محتوای آن باید جدا از مجوز کد بررسی شود.
2. دادهٔ validation و test هرگز به فایل آموزش منتقل نشود.
3. نسخهٔ خام منبع، URL، تاریخ دریافت، checksum، مجوز، تغییرات و روش پالایش ثبت شوند.
4. deduplication دقیق و بررسی نمونه‌ای شباهت معنایی پیش از ادغام انجام شود.
5. محتوای شخصی، حساس، دارای حق نشر نامشخص یا دارای شرایط استفادهٔ محدود بدون مجوز روشن وارد نشود.
6. پیکره‌های بسیار بزرگ بهتر است بیرون از Git معمولی نگهداری شوند؛ GitHub برای نگهداری ده‌ها گیگابایت متن خام راهکار مناسبی نیست.

## محدودیت سخت‌افزار و آموزش

SimaNN فعلی یک مدل کوچک بایت‌محور است. افزودن ده‌ها گیگابایت متن به‌تنهایی آن را به مدل مکالمه‌ای توانمند تبدیل نمی‌کند. برای رایانه‌های کم‌حافظه، باید داده به shardهای کوچک تقسیم شود، خواندن جریانی انجام شود و نمونه‌گیری و ارزیابی مرحله‌ای وجود داشته باشد. قبل از آموزش طولانی، یک benchmark کوتاه روی سخت‌افزار هدف لازم است.

این فهرست توصیه به دانلود خودکار نیست؛ هر منبع باید پیش از استفاده از نظر حقوقی، کیفیت، تکرار و تناسب با هدف بررسی شود.
